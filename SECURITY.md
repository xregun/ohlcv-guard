# Security

ohlcv-guard reads pandas DataFrames you give it. It doesn't read files, open network connections or run code from its
input.

If you find a vulnerability (for example input that makes it hang or use unbounded memory), please report it privately
through GitHub's "Report a vulnerability" on the repository's Security tab rather than in a public issue. You'll get an
answer within 7 days.

Supported versions: the latest release.
